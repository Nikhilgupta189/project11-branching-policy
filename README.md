## Pull Request and Branching Workflow

**Feature Branch:** `feature/update-infrastructure`

**Base Branch:** `main`

**Pull Request:** https://github.com/Nikhilgupta189/project11-branching-policy/pull/1

### Implementation
1. Created a feature branch using Git.
2. Modified Terraform infrastructure metadata.
3. Validated changes using `terraform fmt` and `terraform validate`.
4. Committed and pushed the feature branch to GitHub.
5. Created Pull Request #1.
6. Performed a self-review and documented the findings.
7. Merged the Pull Request into the main branch.
