# Project 11: Infrastructure Changes with Branching Policy

## Objective
Manage Terraform infrastructure changes through Git branches
and GitHub Pull Requests.

## Tools
- Git
- GitHub
- Terraform

## Workflow
1. Create initial Terraform configuration on main.
2. Create a feature branch.
3. Modify infrastructure configuration.
4. Validate changes.
5. Push the feature branch.
6. Open a Pull Request.
7. Review and merge the changes.

## Evidence
Pull Request screenshots will be added after testing.
